# 繁体 → 简体 的字形映射（一行一个 `繁=简`）。
#
# 为什么需要这一层：词表里只写简体，但用户可能用繁体输入法（雅加达华人里有不少）。
# 「賭博」「一把 50 塊錢」如果不去映射，就是同一个词换了个字形，直接绕过过滤。
# 匹配之前先把输入过一遍这张表，词表就只需要维护简体一种写法。
#
# 加词的时候：只要新词里出现繁体独有的字，就在下面补一行；简体里没有的字不用写。
# 只收和钱、赌博、下注相关的字，不收「为/為」「这/這」这类无关的字——
# 这张表只服务敏感词匹配，不是给用户看的繁简转换。

# 词表里出现的字
