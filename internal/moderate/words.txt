# §14 敏感词表：牌局的备注和地点命中这些词就拒绝提交（提示「请勿涉及金钱」）。
#
# 一行一个词，`#` 开头是注释，改完不用改代码、不用发版。匹配规则：
#   - 纯 ASCII 的词（judi、bet…）按**整词**匹配，所以 "bet" 不会命中 "better"、
#     "alphabet"；要额外覆盖写法就再写一行（betting、bets…）；
#   - 含汉字等非 ASCII 的词按**子串**匹配，并且会先去掉空格、连字符和零宽字符，
#     所以「赌 博」「赌​博」都能挡住。
#   - 匹配之前输入会先归一化：小写、繁体转简体（traditional.txt）、全角转半角。
#     所以这里**只写简体**，「賭博」「一把 50 塊錢」同样拦得住。
#
# 口径（和仓库所有者定过）：**宁可漏拦，不可误拦**。
#   判断标准只有一个：这个词出现在备注里，别人看了会不会以为这是个赌局。
#   会 → 放进来；不会，或者只有时候会 → 不放。误拦的代价比漏拦大得多：
#   被拦的人不会再解释一遍，他直接换一个 app。词表随时可以改、改了不用发版，
#   所以不确定的默认不放。
#
# 故意不放的词（都有人问过要不要加）：
#   - bandar：印尼语里既是「庄家」也是常见地名/店名（Bandar Djakarta 是雅加达有名的
#     海鲜餐厅），放进去会误伤；
#   - dadu / kartu：骰子、牌，本身中性，约牌局本来就会说「打牌」；
#   - uang / duit / cash / money：太常用，约局时聊到人均消费很正常；
#   - 红包 / 押金：红包在华人圈里就是普通的社交词，押金是正常的 AA 说法，
#     它们出现在备注里**不会**让人以为这是赌局；
#   - 金额本身（「一把 200」）：不拦，因为「人均 200」是正常需求，靠词表也拦不住
#     只想写数字的人。
