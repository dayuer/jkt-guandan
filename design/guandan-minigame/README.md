# 随时掼掼蛋 · 小游戏适配稿（#142）

二期小游戏用原生 Canvas 画界面（`app/minigame/`），有五处和 H5 设计稿（`../guandan-h5/`）不同：右上角胶囊、原生输入条、时间胶囊行、系统字体、转发卡片。本目录定下这五处的规则。

| 文件 | 用途 |
|---|---|
| `README.md` | 规则和数值（本文） |
| `prototype.html` | 适配稿：每一屏都用 Canvas 2D 画，和小游戏的绘制方式一致。双击就能打开，不用起服务；勾上「模拟安卓」可以看衬线退回无衬线的效果 |
| `screenshots/` | 每一屏的 2 倍图，由 `sh shoot.sh`（headless Chrome）从 `prototype.html#编号` 生成 |
| `screenshots/before/` | 改之前的实现：`main` 22f8fd8 加 PR #144，用无界面脚本渲染。这些图里没有画胶囊，emoji 显示成方框是渲染环境缺字体，真机不会这样 |

**数值以 `../guandan-h5/tokens.css` 为准。** 小游戏里没有 CSS，`app/minigame/src/core/ui.ts` 的 `C` 是令牌的副本；本文只写小游戏新增的尺寸和规则，不重新定义颜色。画面尺寸按 iPhone 14：390×844，胶囊 `{left: 297, top: 51, width: 87, height: 32}`。

## 一、右上角胶囊

截图：M1–M6。

### 1.1 胶囊行和禁区（M1）

所有数值都用 `wx.getMenuButtonBoundingClientRect()` 现算，不写死；拿不到时用 `app.ts` 里的兜底值。

| 项 | 规则 |
|---|---|
| 禁区 | 胶囊矩形向左、向下各外扩 8：`x ≥ menu.left − 8` 且 `y ≤ menu.bottom + 8`。禁区里不放文字、不放热区，装饰也不行 |
| 导航行 | 和胶囊同一行，垂直中线 `navY = (menu.top + menu.bottom) / 2` |
| 内容区顶 | `contentTop = menu.bottom + 8`。滚动内容在这条线以上裁掉 |
| 标题 | 17 / 700 / `--ink`，水平居中。最宽 `2 × (menu.left − 8 − W/2)`，iPhone 14 是 188；超出时末尾省略，不左移，不缩字号 |
| 左槽 | 返回：路径画的箭头，热区 60×44；或文字按钮（如「取消」）：15 / 600 / `--ink-3`，热区 72×44。左槽和标题之间至少留 8 |
| 右侧 | 永远不放我们自己的按钮。原来放在右上角的操作，按 1.3 节挪走 |

### 1.2 Tab 级页面（M2）

- 首页的胶囊行左侧只放低优先级信息：「Jakarta · 雅加达时间」13 / `--ink-3`，离线时后面跟一个 `--khaki` 小点和「离线 · 15 秒刷新」11 / `--ink-4`。整行右端不超过 `menu.left − 16`。
- 大标题「随时掼掼蛋」从 `contentTop` 开始排，不和胶囊同一行。
- 标题右侧的两张小牌，顶边离 `menu.bottom` 至少 8。现在是 `menu.bottom + 2`，见第六节。
- 我的、牌友、学牌三个 Tab 页的导航行只有居中标题，没有左槽。

### 1.3 挪走的按钮

| 页面 | H5 设计稿 | 小游戏 |
|---|---|---|
| 开一局（M3、M4） | 右上「取消」（X1） | **左上「取消」**，不用返回箭头。开一局是从底部「约局」进来的新建流程，用文字说清楚「不开了」。地点或备注里有字时，先弹确认框（M4）：标题「不开这一局了？」，说明「填的地点和备注不会保存」，左「继续填」（soft），右「不开了」（danger）。片区、时间这类选择项不算「填过」 |
| 详情（M5、M6） | 右上「⇪ 分享」 | **底部操作栏第一位**，dark 样式，图标画路径。胶囊「···」里的「转发」也发这一局，用同一张卡片（PR #144） |

详情页底部操作栏：

- 只有一两个操作时排一行：分享宽 110，主按钮占剩下的，间距 12，按钮高 52。
- 三个以上排成 2×2，每格 `(W − 32 − 12) / 2`，行距 8，字号 15。顺序：第一行「分享 / 退出」，第二行「改时间·地点 / 取消这局」。危险操作永远在右下。
- 牌局已取消或已结束时，不显示分享。

## 二、原生输入条

截图：N1–N4、T3。小游戏没有行内输入框：点字段时调用 `wx.showKeyboard`，屏幕底部弹出微信原生输入条和键盘，我们在画布上同步显示文字和光标。

### 2.1 字段状态（N1）

| 状态 | 底 | 边 | 其他 |
|---|---|---|---|
| 默认 | `--card` | 1px `--line` | 占位字 `--ink-4`；单行高 52，多行至少 84；圆角 12 |
| 激活 | `--card` | **1.5px `--red`** | 外面加 4px 焦点环 `--red-ring`（即 `--sh-focus`）；光标 1.5px `--red`，周期 1s，亮 550ms；单行太长时显示末尾，开头用「…」 |
| 激活且快满 | 同上 | 同上 | 字数到上限的 80% 起，右侧显示「36/40」11 / `--ink-4`，文字区让出 44 |
| 出错 | `--err-tint`（#fbefed） | 1px `--red` | 下方 12 / `--red` 的说明，前面是**路径画的**实心圆感叹号（直径 14），不用「⚠」字符 |

字段上方的标签不随激活变色，焦点只靠边框和焦点环表示。

### 2.2 键盘弹起时的页面（N2、N3）

- **可视底边** = 屏高 − 键盘高（`wx.onKeyboardHeightChange`）− 输入条高。输入条高度先按 **56** 预留，#141 真机测试时核对：键盘高度回调如果已经包含输入条，就把这 56 去掉。
- 激活的字段要滚到可视底边上方 16。字段本来就在可视区里时不滚；滚动用 220ms ease-out（`--t-base`、`--ease-out`）。**点字段就要滚**，不只是点「下一项」的时候（现在只有「下一项」会滚，见 before/create-kb.png：地点框被输入条盖住了一半）。
- 键盘弹起时，底部操作栏和 Tab 栏都收起，内容区一直延伸到可视底边。
- 输入条的确认键：后面还有字段时用「下一项」（`confirmType: next`），点了直接激活下一个字段，例如地点 → 备注；最后一个字段用「完成」。
- 点画布上的空白处 = 收起键盘，保留已输入的文字。点另一个字段，直接切过去，不用先收键盘。
- 画布上的文字以 `onKeyboardInput` 为准，和输入条同步；收起时以 `onKeyboardComplete` 的值为准。

### 2.3 弹层里的输入（N4、T3）

- 底部弹层的底边贴在输入条的顶边，整体上移。
- 弹层顶边不高于 `contentTop`（胶囊底 + 8）。放不下时弹层内部滚动，激活的字段必须完整可见。现在的实现没有这个下限：改时间弹层被顶出屏幕顶部，标题看不到（见 before/edit-sheet-kb.png）。
- 弹层里只有一个字段时（如填称呼），弹层打开就直接激活这个字段。
- 居中对话框：在「状态栏底 ~ 可视底边」之间垂直居中。

## 三、时间胶囊行

截图：T1–T3。改时间不用原生日期选择器，用三行胶囊：哪天、几点、几分。

### 3.1 版式（T2）

| 项 | 数值 |
|---|---|
| 行 | 「哪天」「几点」「几分」各一行，**单行横滑，不折行** |
| 标签列 | 左边距 20，宽 48；13 / 700 / `--ink-2`，和胶囊垂直居中 |
| 可视区 | 从 x = 68 到**屏幕右边缘**，右边不留边距，让最后一个胶囊被切开，提示还能滑 |
| 渐隐 | 右侧 32：弹层底色 → 透明。滑过之后，左侧也加 20 的渐隐 |
| 胶囊 | 高 36，圆角 18，宽 = 字宽 + 14×2，间距 8，行距 10；14px |
| 选中 | `--red` 底，`--cream` 字，700 |
| 未选 | `--card` 底，1px `--line` 边，`--ink-2` 字，400 |
| 不可选 | 1px `--line` **虚线**边，`--khaki` 字，没有热区 |
| 摘要行 | 三行下面写「改成 今天 周三 10/14 19:30（原来 20:00）」12 / `--ink-3`；没改时写「还是 …（没改）」 |

### 3.2 内容和溢出

| 行 | 选项 | 文案 |
|---|---|---|
| 哪天 | 今天起 8 天 | 「今天」「明天」，之后是「周五 10/16」 |
| 几点 | 9–23 点，15 个 | 「19点」 |
| 几分 | 4 个 | 「:00」「:15」「:30」「:45」 |

- 打开弹层时，每一行都把选中的胶囊滚到可视区左起约 1/3 处。滚动量不能小于 0，也不能超过最大值。
- 「几分」只有 4 个，放得下就不滚动，也不画渐隐。
- 今天已经过去的钟点画成不可选。从别的日子切回「今天」时，如果选中的钟点已经过了，自动跳到下一个能选的钟点，并把它滚进可视区。
- 原来的开始时间如果不在可选范围里（比如早上 8 点开的局），在对应那一行最前面插一个胶囊显示原值，默认选中，不能删。

### 3.3 和键盘一起出现（T3）

改时间弹层里还有地点字段。编辑地点时，三行胶囊收成一行摘要：`--paper` 底，圆角 12，高 48；左边「时间」13 / 700 / `--ink-2`，中间是选中的时间 15 / 700 / `--ink`，右边「改 ›」14 / 600 / `--red`。点这一行收起键盘，三行胶囊重新展开。

### 3.4 开一局

开一局表单仍然用三个预设：今晚、明晚、后天的 19:30，排一行可以折行，不改。以后要加「其他时间」，复用本节的三行胶囊，做成单独的弹层。

## 四、字体

截图：F1、F2。

### 4.1 字族

| 用途 | 字族（`ui.ts` 的 `SANS` / `SERIF`） | 用在哪 |
|---|---|---|
| 无衬线 | `"PingFang SC", "Noto Sans SC", "Hiragino Sans GB", sans-serif` | 除下一行以外的所有文字 |
| 衬线 | `"Songti SC", "Noto Serif SC", "STSong", serif` | 只用于 ≥ 20px 的标题和数字：详情大时间 44、牌桌「3/4」40、首页大标题 28、弹层标题 20、头像首字、转发卡片的时间 76 |

- 不自带字体文件，也不用 `wx.loadFont`：包体和首屏优先（`docs/minigame-tech.md`）。
- 安卓上大多没有宋体，衬线会退回系统无衬线（F1 右）。**层级只能靠字号、字重和颜色区分**，不能指望衬线和无衬线的差别。检查方法：在 `prototype.html` 里勾「模拟安卓」，层级仍然清楚就算合格。
- 字重只用 400、600、700、900 四档。有的安卓机会把 600 显示成 400 或 700，所以选中和未选中这类状态必须同时换底色或边框，不能只靠字重。
- 小于 20px 的文字一律用无衬线。

### 4.2 符号

| 类别 | 规则 | 例子 |
|---|---|---|
| **画路径** | 颜色要随状态变化的，或者不是每台机器的字体里都有的 | Tab 图标 ♠♣♦♥、首页小牌上的花色、返回 ‹、列表箭头 ›、关闭 ×、勾 ✓、出错 ⚠、分享 ⇪ |
| 可以用 emoji | 只做装饰；颜色不表示状态；旁边一定有字 | 💬 发到微信、🖼 保存海报、📋 复制话术、🕘 改时间横幅、👑 你是局头、🀄 学牌插图 |
| 直接用 | 系统 CJK 字体都有 | · 中点、… 省略号、＋ 全角加号、「」引号、正文里的 → |
| 不要用 | 部分安卓机缺字，会画成方框 | ☆ ★ ✎ ↻ ☰ ⇪ ⚠ ‹ › 〉，以及空心花色 ♤♡♢♧ |

花色要画路径的原因：iOS 可能把 ♠ ♥ 这类字符显示成彩色 emoji，这时 `fillStyle` 不起作用，Tab 选中变红就失效了。`prototype.html` 里的 `icon.spade / club / diamond / heart` 可以直接搬到 `widgets.ts`。

## 五、转发卡片

截图：C0–C5。`wx.shareAppMessage` 的 `imageUrl`，比例 5:4。

### 5.1 版式（C0）

逻辑尺寸 500×400，从主画布导出 750×600（PR #144 的做法）。

| 区 | 规则 |
|---|---|
| 底 | **满版** `--red-deep`，不再留 16 的纸色边：群聊里卡片本身就有白框，再留边会浪费 6% 的面积 |
| 描边 | 内描边 inset 8，圆角 22，8px `--red-ink`；金色虚线 inset 24，圆角 14，2px，`rgba(233,196,106,0.45)`，虚线 [6, 5] |
| 文字区 | 左右各留 48，宽 404 |
| 信息块 | 日期、时间、地点、次要信息四行，作为一块在 y = 36 ~ H − 118 之间**垂直居中**。地点只有一行时，不会在中间留出一大块空 |
| 日期 | 22 / 700 / `--gold`：「今天 · 周三 10/14」，行高 30 |
| 时间 | 76 / 900 / 衬线 / `--cream`，行高 84 |
| 地点 | 26 / 700 / `--cream`，最多两行，行高为字号的 1.3 倍；两行放不下就每次缩 2，最小 20；还放不下，第二行末尾省略 |
| 次要信息 | 「片区 · 玩法 · 局头 称呼」17 / 400，`--cream` 75% 不透明；称呼最宽 104（约 6 个汉字），整行最宽 404，超出都省略。**PR #144 现在没有截断**，长称呼会超出卡片（before/card-longvenue.png） |
| 座位 | 圆心 y = H − 70；4 个圆，r 22，从 x = 70 起，间距 52；局头 `--red-tint` 底、`--red` 字，其他人 `--beige` 底、`--ink` 字；空位是 r 21 的虚线圈，`--cream` 65%。卡片是给别人看的，不显示「我」的金色 |
| 状态签 | 高 44，右边对齐 W − 48，左边不越过 x = 262；字号放不下时从起始值往下缩，最小 14 |

### 5.2 状态签

| 状态 | 文案 | 样式 |
|---|---|---|
| 差人 | 「还差 N 人」（和转发标题一致） | `--gold` 底，`--red-ink` 字，24 / 900 |
| 满座、没有候补 | 「已满 · 可排候补」 | `--cream` 16% 底，`--cream` 字，20 / 700 |
| 满座、有候补 | 「已满 · N 人候补」 | 同上 |
| 已取消、已结束 | 「已取消」「已结束」 | 同上；整张卡片改成灰色：底 #8a7d70、内描边 #6f645a，日期改成 `--cream`。这两种只会在从「···」转发时出现 |

满座时状态签变弱，因为这时最要紧的信息是「已经成局」，不再是招人。

### 5.3 不放的东西

二维码、小程序码、品牌名都不放：卡片下方微信会自动显示小游戏的名字和图标。也不放备注，备注太长，放了会挤掉座位。
