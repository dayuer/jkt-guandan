# 设计稿修改提示词：小程序版 → H5 + PWA 版

> **已完成，仅作历史记录。** 按这些提示词产出的设计稿是同目录下的 `掼蛋约局H5.html`，截图在 `screenshots/`，编号改成了 A1–H8。旧编号和新编号的对应关系，以及服务端设计之后新增的状态，见 [`design/guandan-h5/README.md`](../guandan-h5/README.md)。

配套方案：[docs/h5-pwa-plan.md](../../docs/h5-pwa-plan.md)

用法：先把「0. 全局提示词」发给设计工具，再按屏逐条发送。每条提示词都写成独立可用的，可以单独发。

---

## 0. 全局提示词（先发）

```
把「随时掼掼蛋」这套设计从微信小程序改成移动端 H5 + PWA 网页应用。保留现有视觉语言：米白暖色底、掼蛋红主色、衬线大字号时间、扑克花色图标、底部五栏 Tab（牌局 / 学牌 / 约局（中间「蛋」）/ 牌友 / 我的）。

全局改动：
1. 删除所有屏右上角的小程序胶囊按钮（「··· ⊙」）。
2. 顶部导航改成网页样式：左边返回箭头（一级页面不显示），中间标题，右边一个分享图标（只在牌局详情等可分享页面显示）。导航要能在两种情况下都成立：被微信内置浏览器的标题栏包住时不显得重复；在 iOS 主屏幕 PWA（无浏览器外框）中独立显示。顶部预留安全区。
3. 不再出现任何微信原生控件样式：绿色「发送」按钮、「小程序」字样、微信转发面板。
4. 用户第一次需要身份时（报名或发起），在底部弹层里填一个称呼，不需要登录或注册。
5. 新增一个通用状态条组件「提醒状态」，有三种状态：已开启（绿点）/ 未开启（灰点 + 「开启」文字按钮）/ 本机不支持（灰点 + 「改用日历」）。

文案语气：牌友之间的口吻，简短，不说「授权」「订阅」「PWA」之类的技术词。
```

## 2. 新增屏

### 11 报名成功 · 要不要提醒（核心新屏）

```
新增 11「报名成功」底部弹层，叠在已报名状态的 03 牌局详情上。

内容从上到下：
- 顶部一个红色对勾，加上标题「占上了！」。
- 一张小卡片，概括这局：「周四 10/15 19:30 · Pacific Place · 鼎泰丰包间」，再加四个座位圆点，表示 3/4 或 4/4。
- 问句「开局前 1 小时提醒你？」。
- 主按钮（红色）：「提醒我」。
- 次级按钮（描边）：「加到日历」。
- 最下方文字链接：「先不用」。

另画两个变体：
A. 本机不支持推送：主按钮换成「加到日历」，次级按钮换成「用 WhatsApp 提醒我」，问句下方加一行灰色小字「这台手机收不到网页提醒，换个方式」。
B. 已成局 4/4：标题换成「成局了！4 人到齐」，牌桌座位全部点亮，其余内容不变。
```

### 12 跳出微信引导

```
新增 12「在浏览器中打开」全屏遮罩，在用户在微信或 WhatsApp 里点了「提醒我」之后出现。

- 遮罩为深色半透明，盖在 11 弹层上。
- 右上角画一个手绘风格的白色弯箭头，指向微信右上角的「···」。
- 箭头下方用大号白字分两步说明：
  ① 点右上角「···」
  ② 选「在浏览器中打开」（iPhone 上叫「在 Safari 中打开」）
- 中部放一张小插图：模仿微信菜单的示意图，「在浏览器打开」那一项被高亮。
- 底部小字：「你的报名已经保存，打开后自动认出你」。下面放文字按钮「算了，加日历就行」。
```

### 13 iOS · 添加到主屏幕引导

```
新增 13「放到主屏幕」引导页，用户在 iOS Safari 中、从 12 跳转过来时显示。

- 标题：「iPhone 要多一步，才能收到提醒」。
- 三步竖排，每步配一张 Safari 界面的局部截图示意，关键按钮用红圈标出：
  1. 点底部的分享按钮（方框加向上箭头的图标）
  2. 往下滑，点「添加到主屏幕」
  3. 回到桌面，点「掼蛋」图标打开
- 底部醒目显示一张认领码卡片：「你的认领码 4 8 2 7」，用大号衬线等宽数字，下方小字「主屏幕打开时如果需要，输入这 4 个数字」。
- 页面底部放 Safari 底栏的示意，并用一个跳动的箭头指向分享按钮。
- 最下方文字链接：「不装了，加到日历」。
```

### 14 主屏幕 App 首次打开 · 认领身份 + 开启提醒

```
新增 14，表示从 iOS 主屏幕图标首次打开的状态（没有浏览器外框，全屏显示）。画两步：

14a 认出你：
- 顶部显示应用图标和「欢迎回来」。
- 一张卡片：「你是 阿杰 吗？刚报了 周四 19:30 Pacific Place」，配两个按钮：「是我」（红色）和「不是」。
- 「不是」或识别失败时，展开一个 4 位数字输入框，标题「输入认领码」，四个大号分格。

14b 打开提醒：
- 画一只铃铛插画，标题「最后一步：打开提醒」。
- 说明文字：「开局前 1 小时、有人退出、局头改时间，都会告诉你」。
- 主按钮：「打开提醒」。点击后会弹出系统权限框，可以画一个灰色占位，表示「iOS 系统弹窗」。
- 成功状态：铃铛变实心，显示「搞定，到点叫你」，下方按钮「回到牌局」。
- 拒绝状态：「没关系，可以去 设置 › 通知 › 掼蛋 里打开」，下方按钮「改用日历」。
```
