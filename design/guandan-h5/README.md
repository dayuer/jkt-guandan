# 随时掼掼蛋 · H5 原型（#7）

本目录是给 impl 用的「施工图」，和设计稿的分工如下：

| 文件 | 用途 | 以谁为准 |
|---|---|---|
| `../guandan-offline/掼蛋约局H5.html` + `screenshots/A1–H8` | 设计稿（Claude Design 导出） | **视觉**以它为准 |
| `tokens.css` | 设计令牌：颜色、字体、圆角、阴影、间距、动效，数值从设计稿源码里提取 | **数值**以它为准，impl 直接引入 `app/h5/` |
| `prototype.html` | 手写 HTML 原型：重绘核心流程，并补齐服务端设计要求、但设计稿里还没有的状态 | **状态和交互**以它为准 |
| `screenshots/` | 原型每一屏的截图（2 倍图），文件名就是编号，用 headless Chrome 从 `prototype.html#编号` 生成 | 供 PR 和 issue 引用 |

## 怎么看

```bash
python3 -m http.server 4173 --directory design/guandan-h5
```

- 打开 `http://localhost:4173/prototype.html`，可以看到全部画面和「落座」现场演示。
- `prototype.html#W3` 这样带编号打开，只显示这一屏，按 100% 大小显示，方便在 issue 或 PR 里引用某一个状态。
- 必须通过 HTTP 打开，直接双击文件无法加载 `tokens.css`。

## 招牌交互：落座

页面在前台时收到 WebSocket 的 `seat.taken`，新座位从上方落到牌桌上，带回弹效果，同时「差 N 人」的数字翻动一下。

- 座位：`seatDrop` 动画，时长 `--t-base`（220ms），曲线 `--ease-spring`；
- 计数：`flip` 动画，时长 `--t-base`，曲线 `--ease-out`；
- 系统开启「减少动态效果」（`prefers-reduced-motion`）时，令牌里的时长会变成 0，动画自动关闭；
- 只给**新落座**的那个座位加动画。REST 刷新或重新连接后重绘页面时不加，避免整桌一起跳。

`prototype.html` 顶部的现场演示可以逐条模拟事件：别人报名、我报名（满座时进候补）、别人退出（候补自动补位）、局头改时间、有人在看。

## impl 注意

- 颜色、圆角、阴影、字号、字重、动效只能用 `tokens.css` 里的变量，不要在组件里写死数值。令牌里的字号直接取自设计稿源码（例如详情页的大时间 `900 44px/1.1`）。
- 牌局卡片和牌桌的立体感来自 `--sh-card`，也就是 2px 的「牌边」，不要换成大面积模糊阴影。
- 牌桌**显示时**始终把局头转到最上面，其他人按座位号顺时针排列。这只是显示上的旋转，`seat_no` 本身不变；局头转让后，按新局头重新旋转（见 K2 和现场演示里的「局头退出」）。
- 「我」用 `--gold` 表示，局头用 `--red-tint` 表示；局头本人看自己时，显示金色并带「局头」角标（见 K1、K2）。
- 字体：Noto Serif SC 用于标题和数字，Noto Sans SC 用于正文。生产环境应把字体按实际用到的字裁剪成子集后自托管，不要依赖 Google Fonts（CSP 只允许加载本站资源，见 server-design §10.6）。
