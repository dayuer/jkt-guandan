# #53 / #55 / #56 的验证截图

用 CDP（Chrome DevTools Protocol）精确设定视口后截的，脚本在 `docs/verify/53/shoot.mjs`。
每个视口各 5 张：空列表、长列表（顶部）、长列表（滚到底）、详情页、分享面板。

| 文件 | 说明 |
|---|---|
| `375x812-empty.png` | 首页空列表：底部 Tab 栏贴住屏幕底，空状态文字没有虚线框（#56） |
| `375x812-long-bottom.png` | 长列表滚到底：最后一张卡片完整可见，没有被 Tab 栏压住 |
| `375x812-detail.png` | 详情页：只有底部操作栏、没有 Tab 栏（设计稿 B1），三个空座位是虚线**圆**（64×64，#55） |
| `375x812-share.png` | 分享面板：四个出口，WhatsApp 用品牌绿，面板自己滚不会被切掉 |
| `375x667-*.png` | 同一组，用更矮的屏（iPhone SE）验证 |

顺手记下来的量测（每次截图时从页面里读的）：

| 视口 | 场景 | 文档高 | 底栏位置 | 最后一张卡片 |
|---|---|---|---|---|
| 375×812 | 空列表 | 812 | 768–812 | — |
| 375×812 | 长列表（底部） | 1338 | 768–812 | 底边 720 |
| 375×812 | 详情页 | 812 | 753–812（操作栏） | 646（空座位 64×64） |
| 375×667 | 空列表 | 667 | 591–667 | — |
| 375×667 | 长列表（底部） | 1338 | 591–667 | 底边 575 |
| 375×667 | 详情页 | 752 | 576–667（操作栏） | 646 |

底栏的 `bottom` 始终等于视口高度，最后一张卡片始终在底栏上沿之上——这两条就是 #53 的判据。

空座位的量测：`document.querySelector('.disc.empty').getBoundingClientRect()` 是 **64×64**。
#55 修之前它是 64×100——页面空状态那条 `.empty { padding: 48px 24px }` 落在了同一个类名上。
现在页面空状态改叫 `.empty-state`，`.disc.empty` 也显式写了 `padding: 0`。
