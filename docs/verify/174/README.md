断言（全部 PASS）：
- 第 4 项：2 小时后开局 `can_start=false` 无入口条且挂了重新拉的定时器；15 分钟后开局 `can_start=true` 有入口条。
- 第 3 项：别人记了一局、顶部条出现后立刻返回，`strip`、`flip` 都清空，`app.anims` 为空。
- 第 5 项：GET 每局带 `seats`，第 2 局 2 号是 Lily、第 5 局是老张。
- 第 1 项：是我记的但结果不一样 → 弹 S12；「用刚才的」保持第一次的结果。改一局时另一次同样的 PUT 先写进去（模拟响应丢失），再提交收到 409 `round_changed` → toast「改好了 · …」，不提示「刚被别人改过」。
- S15 卡片导出 750×600；第 6 项顶部条文字是「黑方 头游」。

没在截图里覆盖、只靠单元测试的：第 2 项（revision 有缺口时重新拉整份；真服务端不会漏推，脚本里造不出缺口），见 `app/minigame/src/lib/scoring.test.ts`「实时 score.round 拼接」。
